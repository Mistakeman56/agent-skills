# 小众中国品牌/产品调研

当用户问"XX新品牌/小厂的东西能买吗""原来只有一家特别贵，现在出了好几家便宜的"时使用。典型场景：客制化外设（键帽/键盘）、新消费品牌 vs 头部老牌。

## When to Use

- 用户刷到新品牌（小红书/抖音），想知道靠不靠谱、能不能买
- 新品牌 vs 老牌头部（如 山海Cerakey vs 御极/隅界/CeraX）价格差很多，问值不值
- 需要判断"小厂做工质量 + 真实口碑 + 价格合理性"

> 订阅制网络服务（VPN/机场）的选购比价不属于本 skill → 走 `vpn-airport-research`（隐晦措辞要求 + 官网验真流程不同）。

## 工作流程

1. **用 Exa SDK 直查**（用户明确偏好，别用默认 web_search）：
   ```bash
   cd ~/.hermes/hermes-agent && source venv/bin/activate && python3 -c "
   import os
   for line in open('~/.hermes/.env'):
       line=line.strip()
       if line and not line.startswith('#') and '=' in line:
           k,v=line.split('=',1); os.environ.setdefault(k,v)
   from exa_py import Exa
   exa = Exa(os.environ['EXA_API_KEY'])
   r = exa.search('品牌名 品类 评价', num_results=5, type='auto')
   for res in r.results:
       print(res.title); print(res.url); print((res.text or '')[:250])
   "
   ```
2. **圈内社区优先**：客制化外设查 zFrontier（装备前线）帖子——玩家主动发帖讨论的才算"圈内认可"级别（例：御极"观火"系列在 zFrontier 有"烧废无数才留下"的工艺帖）
3. **电商图文交叉验证**：淘宝好物网/商品页的深度体验文（例：隅界竹桃笙118键528元、五面热升华工艺）
4. **行业媒体确认背景**：每日商报/界面等报道确认品类是否成熟（例：达尔优大厂也出陶瓷键帽 = 工艺成熟度上升）
5. **信息最少的品牌明确标注"资料少需观望"**（例：CeraX 公开资料不足，建议等小红书/淘宝评价多了再买）

## 产出结构

按品牌逐个分析（真实存在性 → 圈内讨论/体验文 → 价格 → 工艺/特点），最后给结论：
- 能买吗 / 优先哪个 / 哪个先观望
- 买前必问客服清单（该品类的行业通病）
- 关键判断：小厂 vs 头部的差距通常在工艺细节和次品率，价格能打下来说明市场成熟了

## Pitfalls

- **⚠️ 社区帖子 ≠ 实时状态（2026-08 用户当场纠正）**：搜到"社区一片哀嚎/大量同类反馈"时，先分清是**历史帖子**还是**当前正在发生**——用户会直接问"你说的哀嚎是现在正在发生的吗？"。引用社区反馈要标注时间（"1月/3月的帖子"），不要把几个月前的帖子说成当下现象。判断实时性：看发帖日期、官方公告日期，或直接再搜一次"今天/本周"的反馈
- **⚠️ Exa 对小红书/抖音/B站内容索引很弱**：新品牌在小红书火不代表 Exa 能搜到。搜不到不代表不存在，转查 zFrontier/淘宝好物/行业媒体
- **⚠️ 陶瓷键帽行业通病（所有厂都要解决）**：烧结尺寸收缩导致键帽歪斜——买前必问"歪斜率/怎么解决"
- **⚠️ 陶瓷键帽是工艺品**：官方图都打光，釉色质感要看买家秀；陶瓷脆，问断裂保修/运输损坏政策
- **⚠️ 价格口径要算单颗价**：一套114颗1070元 vs 118键528元，直接比总价没意义，换算均价（山海~9.4/颗，隅界~4.5/颗）
- **⚠️ 区分"规模化量产陶瓷键帽" vs "手工定制单颗"**：后者（软陶立体造型，几十到几百/颗）更脆弱，只能装ESC等特殊键位

## 案例速查

- 2026-08 陶瓷键帽调研：山海Cerakey（蓝裂纹114颗1070元，贵）vs 御极YUJI（zFrontier有工艺帖，圈内认可）vs 隅界（118键528元，五面热升华，有深度体验文）vs CeraX（资料少待观望）。结论：200-300价位与高端PBT接近，值；御极/隅界优先，CeraX观望。详见 references/ceramic-keycaps-2026.md
- 2026-08 手工剪刀调研：剪胶带要防粘=涂氟，锋利=镀钛，最优解是"镀钛+防粘涂层"二合一（3M SS-T7）。对比国誉WSG-HSF251涂氟剪/得力特氟龙/SDI。详见 references/scissors-buying.md
