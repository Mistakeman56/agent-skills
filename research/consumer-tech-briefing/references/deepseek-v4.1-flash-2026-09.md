# DeepSeek V4.1 Flash（2026-09-10 发布）— 事实速查

> 数据截至 2026-09-10。价格、榜单会变动，引用前先核。

## 是什么
- DeepSeek **首个原生多模态**模型（出厂图文一体，非"纯文本底座外挂视觉编码器"），MIT 开源。
- 新架构 **CED（Causal Encoder-Decoder）**，输入/输出非对称：
  - 读（输入）激活 ~8B，写（输出）激活 ~16B
  - 总参 **552B** MoE，40 层，384 路由专家（每 token 激活 6）+ 1 共享专家，FP4 专家权重
- **KV Cache 压缩**：全局 KV ≈ **890 字节/token**；HBM 需求降至 1/4、SSD 至 1/8。
- 上下文：**1M 输入 / 384K 输出**。
- 速度（对比前代）：长文检索 **5.2×**、SVG 生成 **6.0×**、SQL **5.0×**、回文算法 **4.6×**、asyncio **3.9×**。
- 训练：45T token 多模态预训练。
- API 模型名：**`deepseek-flash`**（旧名 v4-flash / v4-flash-vision-exp 自动路由）；**`deepseek-v4-pro` 自 2026-09-14 起下线**并路由到 V4.1 Flash。
- 官方概括三词：**更强、更快、更普惠**。
