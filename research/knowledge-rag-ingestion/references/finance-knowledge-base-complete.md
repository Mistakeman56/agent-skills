# A股金融知识库 Complete（以"经验/实践型领域"为例）

## 概述
- **领域**：A股股票投资分析与实战交易（35条/330段落/~140K文本）  
- **成本**：¥1.45（子Agent并行3路 + 直接工作）  
- **特点**：非 canonical（无标准教材），知识来自网络文章、博客、论坛、券商研报  
- **用途**：辅助用户模拟交易决策（持仓巨化股份600160、佰维存储688525）

## 与教科书类知识库的关键区别

| 维度 | 408教科书类（OS/DS/CN） | 经验/实践类（金融/A股） |
|:----|:-----------------------|:----------------------|
| 知识源 | 王道/汤小丹等权威教材 + 少量博客交叉验证 | BrightData搜中文网文为主（知乎/雪球/东方财富/券商） |
| source_url可信度 | 4-5分（教材/官方文档） | 3-4分（多为个人博客/媒体） |
| 知识稳定性 | 高度稳定（几十年不变的概念） | 部分内容随市场变化（如注册制改革、新概念板块） |
| 用户场景嵌入 | 可选（如用户内网IP段替换） | **必须**（持仓股票、模拟账户参数直接填入知识块） |
| 内容风格 | 定义→特征→分类→算法 | 实战技巧→参数标准→失败案例→适用场景 |
| 子Agent prompt | "使用canonical知识+搜索交叉验证" | "搜索为主+从多篇文章中提取共识" |
| 字段适用性 | 全部17字段严格对齐 | 17字段同样适用，但`architecture_modules` = 分类/分析框架 |

## 研究阶段经验

### 搜索策略
- **BrightData是主战场**：对中文金融/股票内容的搜索效果远好于Bing（openwebsearch）
- **搜索方向**：拆成6个独立方向分别搜，每个方向5条结果，避免混杂
  - A股规则 / 技术分析 / 基本面 / 概念炒作 / 行为金融 / 交易策略
- **来源选择**：优先东方财富、雪球、知乎、券商官方；避免低质聚合站

### 多源共识机制
金融知识的主观性强，同一话题（如"PE估值"）需从至少3个不同文章提取共性：
- 知乎基本面数据4大类 → 给出了PE/PB/PS的适用场景
- 雪球价值投资进阶 → 补充了PE/PB与ROE的关系推导
- 聚宽单因子检验 → 提供了实证数据支撑
- trader信号 → 补充了PE<20、PB<2的量化筛选标准

## 知识蒸馏阶段经验

### 子Agent分工策略（3路并行）
```
Agent1: A股基础(5条) + 基本面(5条)     = 10条
Agent2: 技术分析(8条) + 概念炒作(7条)  = 15条  
Agent3: 行为金融(5条) + 实战策略(5条)  = 10条
```

### 关键成功因素
1. **用户持仓嵌入**：在prompt中明确告知用户持仓（巨化股份600160、佰维存储688525），每条知识块中用实际持仓举例
2. **A股特有机制强调**：T+1、涨跌停板、打板文化、电风扇轮动——这些A股独有特征必须在知识块中突出
3. **实战参数具体化**：不是"设止损"，而是"-5%止损对应20万仓位亏1万=总资金2%"
4. **分批次入库验证**：全部生成完成后统一入库，用3个不同角度关键词验证

### 遇到并解决的问题
- **字段名一致性**：子Agent容易自创字段名（如"架构_modules"而非标准"architecture_modules"） → prompt中逐行粘贴17字段名，事后grep验证
- **financial/非计算机的architecture_modules**：金融领域没有"存储结构"，需要引导子Agent理解为"分类体系/分析框架"
