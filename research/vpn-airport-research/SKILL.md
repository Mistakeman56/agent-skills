# VPN / 机场订阅选购调研

the user said 「搜点好用的 VPN」「比价看看有没有更好的」「官网我看看」「XX 还能不能用」时使用——即订阅制网络加速服务的选购、比价、官网/套餐核对。实体消费品调研走 niche-china-brand-research。

## 铁律（每次适用）

1. **隐晦措辞（用户明确要求，该类内容曾触发平台警告）**：涉代理话题默认「代号 + 委婉词」（网络加速服务/订阅/线路/那家），少堆敏感关键词，不甩品牌清单大表、不主动刷链接。先给 2-3 个代号（如「实测王」「全线内网」）+ 一句特征 + 主力档价格，用户点名哪家再单独展开细节和官网链接；展开时也保持小表格。这是措辞与信息密度偏好，回答内容本身照常完整。
2. **结论 = 1 个最优方案**（用户全局偏好）：比价表只是支撑材料，最后给单一推荐 + 执行步骤。
3. **付费周期上限 = 年付**：永远「月付试水 2 周 → 年付」；试水必测晚 22–23 点 + 常用 AI + 目标地区节点。两年/三年折扣一律不碰（跑路风险）。
4. **价格必须带核验日期**：每个价标注来源核验日；超过 ~6 周的价声明「偏旧，以站内结算页为准」。套餐页常在注册登录后才显示 → **不代注册**（外部写操作），让用户自己注册对账。
5. **兼容性先核**：家里是 OpenClash/Mihomo 内核 → VLESS/SS 都能跑，订阅必须是 Clash/Mihomo 原生 YAML 格式；NAS 做种走直连规则、不占订阅流量；给路由器换订阅时保留自写规则。

## 工作流程

1. **摸行情**（web_search = Exa，用户指定）：查询组合「机场推荐 <年份> 稳定 价格」「<年份> 机场测速 对比 月费」「best VPN for China <年份> price」+ 对候选逐家「<名> 套餐 订阅 设备 流量」。至少 3 个**独立**测评站交叉，逐家记录：真实月付价 vs 年付折算价、线路类型（IEPL/IPLC/中转）、核验日期、实测数据新旧。
2. **官网验真（防钓鱼镜像）**：按 `references/official-site-verification.md` 的双链收敛法执行——两条独立测评站跳转链落到同一品牌域名家族 + 浏览器 title 核对，才算真官网；同时点名搜索结果里的模板垃圾站。
3. **新鲜度实锤**：打开官方入口（线路检测页）看线路可用数/实时延迟，确认站活着；再把「注册后以当日价对账」写进交付。
4. **产出**：默认代号模式 → 用户点名后给单家/两家小表 + 风险点 + 单一方案 + 验真过的入口链接 + 试水步骤。

## 价格判读规则

- 「¥7/月」多为**年付折算**，真实月付通常 2–3 倍 → 两个价都列，不被低价锚定
- 每 GB 单价可能**倒挂**（档位越高越贵）→ 按月用量对号入座，不劝买大档
- 测速榜/排名多为付费投放且互相抄 → 排名只当线索，「独立实测 + 核验日期」权重最高；只有一轮非晚高峰实测的新店必须先月付
- 「不限时/永久流量包」单价普遍比订阅贵数倍，仅低频备用
- 渠道价与官标价冲突（优惠码/邀请价）→ 给区间、注明来源，以结算页为准

## Pitfalls

- web_extract 报 `private or internal network address` = DNS 异常解析到内网假 IP → 改 `curl -sL` 直连，不通再 `-x http://127.0.0.1:7899`（详见 cn-blocked-api-access）
- 测评站外链多为短链（如 ilil.uk）与 `*aff` 域名，属正常推广链：`curl -sL -o /dev/null -w '%{url_effective}'` 跟到底；落点带 `#/register?code=` 邀请参数正常
- 浏览器报 `no close frame received or sent` = daemon 掉线 → 换独立 `session=<名字>` 重开，不要原地重试
- 多步跳转后先确认当前 tab 在目标页再点击（跳转链会串 tab，点错页只会返回 notfound）
- 这类面板站多是 Vue SPA：静态 HTML 里 `<a href>` 常为空 → 要读 JS 渲染后的 DOM，或从入口页按钮文字（立即前往/访问）触发跳转；扒 JS 里域名时注意 `example.com` 占位符
- 给用户链接优先给**入口页**（自动挑线），不给某条具体线路域名（会轮换），并提醒收藏防失联
