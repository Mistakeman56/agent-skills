# 官网验真（机场/订阅类站点）

该品类搜索结果里假镜像站横行，付款前必须确认真官网。SKILL.md 铁律第 4 条「价格以站内结算页为准」的前提就是入口来自这里。

## 双链收敛法

1. 扒 **≥2 个互相独立**（不同运营方）测评站的官方入口外链：
   `curl -sL --max-time 20 '<测评页>' -o /tmp/p.html && grep -oE 'href="[^"]+"' /tmp/p.html`
   过滤测评站自身域名、社媒域名，剩下的为候选（多为短链或 `*aff` 域名，属正常推广链）。
2. 跟随跳转拿最终落点：
   `curl -sL -o /dev/null -w '%{url_effective} %{http_code}' '<候选>'`
3. **判定**：两条链的最终域名属于同一品牌词家族（域名里的词与品牌名对应）→ 收敛可信；不收敛 → 找第三个独立源，收敛前不在任何一站付款。
4. **官方社媒频道是最高权重源**：该品牌 Telegram 频道/Twitter 简介常直书官方地址（bio 一行字就够），与测评链落点一致即视为收敛成立；比第 3 个测评站更硬。
5. 浏览器打开最终站，核对 title/页头 = 品牌名；记录**入口页**（这类站常有「线路检测」入口，自动挑最快线路）。
6. 注册/登录页可打开看结构，但**不代用户注册**（外部写操作、需邮箱）；套餐价常在登录后才显示 → 交付时明确「注册后以当日价对账」。

## 实测开箱（交付前必做，「能打开」必须是实测结论）

主站 + 所有可疑同名站放一轮 curl 全测——搜索结果的印象不算数：

```bash
for u in https://main.example.com https://suspect1.example.net ...; do
  printf '%s -> ' "$u"
  curl -sL -o /dev/null --connect-timeout 8 --max-time 15 -w '%{http_code} final=%{url_effective} ' "$u"
  curl -sL --connect-timeout 8 --max-time 15 "$u" | grep -oE '<title>[^<]*' | head -1
done
```

- 记三样：状态码、最终落点、title。**title 对得上只是必要条件**（假镜像会照抄标题），收敛链才是充分条件。
- **多个导航域名全部落到同一张导航页**（哪怕落地域名换了域名家族）= 官方导航基建收敛成功，可交付；单个孤域名落陌生页 = 存疑，不给。
- 直连不通 ≠ 假站，可能只是被墙 → 追加 `-x http://127.0.0.1:7899` 复测，交付时标注「直连可用 / 需代理」。

## 收敛失败怎么办

独立测评站明示「同名站多个、未能确认哪个是官方」时**不要猜**：只交付多源共同指向的主站，其余同名站逐个点名标「归属未确认，勿在站上注册付款」；再加找一个官方侧来源（社媒 bio、客户端内置地址、官方邮件页脚）重收敛，收敛前不下单。

## 假站 / 镜像特征

- 页面只引用自身域名、通用模板占位文本、没有真实套餐明细
- 同一品牌搜出多个「官网」且风格各异；来自搜索广告位
- 域名与双链收敛出的品牌家族对不上
- 从「行业门户/百科/短链」直接跳品牌站（推广链伪装成官网入口），绕过收敛核验

## 交付清单

- 实测过的**入口链接**（给入口页，不给会轮换的具体线路域名），每个标注直连/需代理，提醒用户收藏防失联
- 点名搜索结果中的假站与**归属未确认的同名站**，防止用户误入注册付款
- 价格表：核验日期 + 优惠码 + 「以站内结算页为准」
