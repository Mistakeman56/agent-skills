## Method A: US Region via Apple Gift Card

**Steps:**
1. Open 招行App → enable overseas cardless payment + set overseas spending limit
2. Ensure US Apple ID has a **tax-free state** address (Oregon OR / Delaware DE / others)
3. Go to https://www.apple.com/shop/gift-cards
4. Select Email delivery, amount $20, checkout with **Apple Pay** (uses your 招行 card bound to CN Apple Pay)
   - Billing address: `1234 SW Broadway, Portland, OR 97201` (Oregon = tax-free)
   - Phone: `503-555-0199` (Portland area code, fake number is fine)
5. Wait for email with redemption code (usually 1-60 minutes, can be up to 24hrs for first purchase)
6. In iPhone **App Store** (NOT system settings), log into US Apple ID
7. Tap avatar → Redeem Gift Card or Code → enter code
8. Open ChatGPT App → Settings → Subscribe → Plus → confirm Apple ID payment

**Known issues:**
- First purchase may trigger fraud review by Apple → delayed email (up to 24h)
- Do NOT re-order while waiting — duplicates both get stuck
- If email never arrives: check spam, or check order status at https://orderstatus.apple.com
- As last resort: contact Apple US support 1-800-MY-APPLE

## Method B: Turkey Region via Apple Gift Card (Cheaper)

**Steps:**
1. Register a Turkish Apple ID at https://appleid.apple.com → country/region = Turkey
2. Use a Turkish address generator: https://www.meiguodizhi.com/tr-address
3. Phone number: your own real number (no Turkish number needed)
4. Buy Turkish iTunes gift card:
   - Option 1: `oyunfor.com` — accepts international cards, but Chinese SMS verification sometimes fails
   - Option 2: **闲鱼** search "土耳其Apple礼品卡" — cheapest, instant delivery
   - Amount: ₺500 (one month of ChatGPT Plus)
5. Redeem in App Store (Turkish account) → Redeem Gift Card
6. Subscribe to ChatGPT Plus via in-app purchase
7. It's recommended to use a Turkish VPN during setup
