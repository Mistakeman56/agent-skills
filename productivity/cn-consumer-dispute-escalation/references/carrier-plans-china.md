# 中国流量套餐：档位结构、网速价位、避坑

## 运营商选择（按地区给结论）

| 运营商 | 取舍 |
|---|---|
| 联通 | 北方一般**性价比最高**，大流量卡最便宜、可办城市多 |
| 电信 | 5G 速率稳，套餐也不错 |
| 移动 | 信号覆盖最稳但**最贵** |
| 广电等虚拟运营商 | 700MHz 覆盖广但容量小、**移动基站上调度优先级低**，拥塞时体感差 |

## 低价大流量卡的统一结构

19–40 元档的"200G 卡"基本都是这个形状，比较时只看这几列：

| 列 | 为什么重要 |
|---|---|
| 通用流量 | 真正的可用量；定向/夜间流量不算数 |
| 通话分钟 | 100–300 分钟是常见档 |
| 合约期 | 3 / 6 个月可接受；12/24/36/48 个月慎入 |
| 优惠期后价格 | "29 元"常是首年价，第 8 个月起跳档 |
| 达量降速阈值 | 超过阈值限速至 1Mbps |
| 年龄/地域限制 | "18–27 岁""省内专属"会决定能不能办 |

**不要凭记忆报具体套餐名和价格**——这类套餐每月翻新，名字和条款都变。
做法：用 `web_search` 搜"<省/市> 流量卡 推荐 <年月>"，从结果里抽**结构**（上表六列），
并对用户明确"以官方 App / 10010 核对为准"。

## 网速：把"快不快"说成实数

| 档位 | 峰值标称 | 实测区间 |
|---|---|---|
| 5G 基础档（低价流量卡） | 500 Mbps | 300–500 Mbps |
| 4G 回落 | — | 100–300 Mbps |
| 5G 优享 / 极速 | 1 Gbps / 2 Gbps | 需 129 元+ 档套餐 |

延迟约 18–20 ms（够打游戏）。

**降速后的真实体感**（比峰值重要得多）：

| 限速后 | 下载速度 | 能干什么 |
|---|---|---|
| **1 Mbps** | ≈128 KB/s | 微信文字可以，**视频基本不行** |
| 3 Mbps | ≈420 KB/s | 720P 勉强 |
| 7.2 Mbps | ≈890 KB/s | 1080P 偶有缓冲 |

⇒ 结论句永远是"**通用额度够不够**"，不是"标称多少 G"。

## 测速取证协议（拿给客服 / 工信部用）

测速站点（直连可用，无需代理）：
- **运营商自家 App 的网络诊断/测速** ← **首选**，投诉时客服只认自家数据，还能看到小区 ID
- https://www.speedtest.cn/ （中文、国内节点多、能截图）
- https://fast.com/ 、 https://www.speedtest.net/

步骤：
1. **关 WiFi**，只用流量；**手动选本地节点**（别用"自动选择"）。
2. **分时段**各测一次：早 9–10 点 / **晚高峰 20–22 点** / 深夜 0–1 点，**连测 3 天**。
3. 每次截图要能看见**时间 + 下载 + 上传 + 延迟**。
4. ⭐ **跨运营商对比**：同一位置插一张别家的卡再测。
   - 都慢 → 基站拥塞，不是本家的锅；
   - **只有本家慢** → 被限速，这才是免费解约的证据。

## 校园卡（学生最划算）

- 需要学生身份（**研究生也算**），学生证 / 录取通知书；
- 常见 25–39 元 / 60–150G / 带视频会员，部分**无合约**；
- 常有"寒暑假流量自动升全国""夜间流量不计入"；
- **只在 8–10 月开学季**各大高校设点办理 → 开学后去学校营业厅办。

## 常踩的坑

1. 只看总流量不看通用额度；
2. 签 36/48 个月合约（想退时要付违约金）；
3. 没确认优惠期结束后的月租；
4. 从广告站 / 小渠道下单 → 首充不到账、虚标流量；
5. 以为"信号好不好"看套餐档次 → 其实看频段覆盖和该地基站负载，**先测信号再办卡**。
