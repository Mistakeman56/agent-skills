# 中国运营商套餐 / 消费合约纠纷

覆盖两类问题：**（A）选套餐**（给谁办、办哪家、哪档最划算）和 **（B）想退掉已签的合约**
（"太卡了能不能不办了"、"合约期三年怎么办"）。

## 铁律

1. **先诊断，再谈退**。"慢"有几种成因，只有一种是运营商违约；诊断错了就会去要一个要不到的免费解约，
   或者白付一笔本可免掉的违约金。

| 成因 | 特征 | 判定 |
|---|---|---|
| **达量降速** | 用满阈值后掉到 1Mbps（只能发文字） | 条款，非违约 |
| **定向流量池用尽** | 低价大流量卡的"通用流量"其实很少，通用跑完即变慢 | 条款，非违约 |
| **基站拥塞 / 优先级低** | 晚高峰暴跌，其他时段正常；同一位置**只有这张卡**慢 | **服务质量问题 → 可要求免费解约** |
| 覆盖差（频段/室内） | 固定地点长期弱信号 | 看合同，一般可协商 |

   查真相的**第一动作**：让用户打开**运营商自己的 App → 套餐余量**，看"通用流量 vs 定向流量"和
   「达量降速阈值」——多数"太卡"在这一步就结案了。

2. **证据先于情绪，且必须在销户之前取**。销户后账单和流量记录一起消失，投诉就没料了。
3. **升级阶梯**：客服 → 运营商省级投诉 → **电信用户申诉**（须先向运营商投诉且未解决，或对其答复不满意）。
   电信类纠纷归通信管理局/工信部；12315/消协对运营商作用弱。每次通话**要工单号 + 录音**。
   **⚠️ 申诉热线有地区差异，拨号前先查本省公告**：部分省已把 12300 并入 12345（如辽宁 2021 年起），
   直接打 12300 可能空号。**网上申诉优先**：本省通信管理局官网 →「公众参与-用户申诉」，留痕且不受热线合并影响；
   工信部受理中心作兜底。
4. **算时间成本**：违约金 ≤ 约 100 元就付钱走人，别用几小时投诉换几十块；
   **合约首月是退出成本最低的窗口**——要退就当期退，越拖越贵（很多渠道首月销户不收违约金）。
5. **谈不下来的那句话术**（用户可直接照念）："网速长期达不到标准，属于服务质量问题。
   我不接受违约金，如果解决不了我直接向工信部申诉。"

## C. 捆绑销售 / 违法搭售（"想买 A 必须先买 B"）

典型形态：买校园网/宽带/IPTV 必须办指定手机卡、已有同家号码也不行、必须换指定套餐档。
**定性：不是"没有选择"，而是"不搭售的选项被刻意做残"。** 识别三件套：

| 手法 | 特征 | 为什么仍是违法 |
|---|---|---|
| **同价不同质** | 同样价格，搭售档给 60G/100M，免搭售档只给 20G/50M | 以办卡为享受正常服务的前提 = 附加不合理交易条件 |
| **惩罚性替代品** | 免搭售档反而更贵（如年付 390 > 捆绑年费 240/360）| 选择权被架空 |
| **强制长周期** | 只给包年/包年不予退费，而用户实际只用数月 | 不合理加重消费者责任的格式条款，无效 |

**法律依据（引原文，别转述）：**
1. **《反垄断法》第十七条第一款第五项** —— 没有正当理由搭售，或交易时**附加其他不合理的交易条件**。
   若经营方是该场景的**独家提供者**（校园/园区/公寓内），即可主张其在相关市场具有支配地位。
2. **最高法指导案例 79 号**（广电捆绑收视费案）裁判要旨：**"经营者即使存在两项服务分别收费的例外情形，
   也不足以否认其构成反垄断法所禁止的搭售。"** ← 这条堵死"我们有替代方案"的抗辩；
   判准是消费者**能否真正、无惩罚地单独选择**。**建案子时直接引用此判例，被投诉方几乎无反驳空间。**
3. **《消法》第九条（自主选择权）、第十条（公平交易权，有权拒绝强制交易）**。
4. **行业主管专项文件**：工信部《关于进一步规范基础电信运营企业校园电信业务市场经营行为的意见》
   明文禁止"强制用户选择移动业务和宽带业务等组合类资费方案，不提供套餐包内各单项业务的资费方案供用户选择"；
   **同一文件还明文写：不得"借口已与学校方面达成书面或口头协议，限制或损害用户的知情权、选择权"** ←
   这条预先把"我们和学校签了合同"这种抗辩封死。教育系统另有"不得捆绑式、强制性销售"的联合通知。
   **检索技巧：投诉前搜"校园电信 15 个不得""××〔年份〕××号 校园电信"找现行专项文件，引条文号比引法条更有效。**
5. **《民法典》第四百六十五条**：合同只约束缔约方 —— 企业与用户所属单位的协议**不能限制用户本人的法定权利**。
   第四百九十七条：不合理加重对方责任的格式条款无效。

**投诉对象要分两条线**（学校/单位参与时）：
- **企业** → 通信管理局 / 电信申诉（程序上不碰单位，但企业被查时可能与单位通气，风险降到低但非零）
- **单位（学校/物业）** → 教育主管部门 / 住建或市场监管（依据"不得签排他协议"类专项规定）
- 加分动作：**要求单位公示收费依据与合作协议**（教育系统文件普遍要求"建立费用公示制度"）——
  排他条款一旦公开就是直接证据。

**取证清单（胜败在此，先取证再谈判）：**
1. **购买/办理页面逐张截图**，尤其"须绑定 XX"那行小字的特写 ← **页面自己展示的歧视结构是最硬的证据**
2. 免搭售档与搭售档的**并列对照截图**（同价不同质一眼可见）
3. 营业厅/客服录音，问一句 **"我已有你们家号码，能不能只买 A 不办 B"**，录下"不行" ← 决定性
4. 通话工单号、缴费记录

**申诉材料一次成型（用户偏好）**：同出 **.md（复制进网上申诉表）+ 可打印 PDF** 双份，含：
套餐对照表、手法分析、逐条法条原文、编号诉求、证据清单、电话口播稿。法律依据**引条文原文**而非转述。
**⚠️ 转完 PDF 必须核对产物存在且非空再发** —— 转换器报成功不等于产出文件（`soffice --convert-to pdf` 会静默失败、退出码仍为 0）；失败就改用 Playwright 的 `page.pdf()`，可靠。发件时 MEDIA: 附上 .pdf 与 .md 两份。

**诉求怎么提才可能实现**：别只要"允许单买"，要**同质同价的单项方案**（"12 元/月给 60G/100M"），
再加"按实际使用月计费/寒暑假可停"。同价同质对方无法反驳，因为价格已经在页面上标了。

**⚠️ 谈判中不要接受"送话费/送流量/打折"作为和解** —— 那是买断诉求的手段。要的
是"不搭售也能买"的选项。

## 选套餐的核对清单（按重要性排）

1. **通用流量**（不是"定向/夜间/校园"）——只认通用额度和达量降速阈值；
2. **合约期**：越短越好，**避开 36/48 个月**；
3. **优惠期结束后恢复多少钱**、是否要**首充**（常见 100 元）；
4. **渠道**：只在运营商官方 App / 官方旗舰店 / 线下营业厅办；
5. **先测信号再选运营商**：在用户常去的地点（宿舍、实验室、家里）用不同运营商的卡各测一次。

**学生身份（含研究生）= 最便宜的一档**：开学季（8–10 月）校园卡通常 25–39 元就含 60–150G，
还常有会员、无合约。用户是学生时，先提校园卡，再谈社会渠道流量卡。

详细档位结构、网速价位、测速取证协议、避坑点见 `references/carrier-plans-china.md`。

## 掉坑清单

- **别把"达量降速/定向池用尽"说成运营商违约**——用户据此去投诉会碰壁，先查余量是省时间的动作。
- **广告站（号卡分销站）的报价不等于官方在售价**：同名套餐的月租、合约期经常对不上。
  一律标注"以官方 App / 客服核对为准"，并让用户下单前打客服确认。
- **别推荐"不限量"**：三大运营商已无真不限量，全是达量降速。
- **虚拟运营商/低价捆绑卡（如广电）**信号与调度优先级在部分区域明显弱于三大运营商；
  用户已踩过一次时，别再推同一家。
- **移动信号最稳但最贵；北方一般联通性价比最高**——按用户所在地区给结论，别给泛泛排名。
- **"我们有替代方案"不等于合法**——见 C 节的"惩罚性替代品"三件套。第一动作是让用户把购买页面
  **逐张截图**（含小字），页面自带的歧视结构比任何话术都管用。
- **⚠️ 当被投诉方与用户的所属单位（学校/公司/物业）有合作协议时，先评估报复风险。** 默认建议
  **脱离隶属关系后再正式出手**（拿到毕业证/离职后），但**证据保全必须立刻做**——网页会改版、录音会丢、
  客服记录只留数月，而民事诉讼时效长达 3 年，晚告不吃亏。只告企业不告单位可降低风险但归不了零，
  别向用户承诺"完全不会被知道"。
- **⚠️ 别把手机号/密码/密钥写进要提交给监管部门的材料正文**——申诉书里只写事实、条文、诉求、证据清单。

## 回答格式（用户偏好）

- **第一句就给结论**（能退不能退、办哪家、多少钱），**再**给表格；
- 用户问"多少钱/多少 G/网速"要横向对比表时，"网速"列写实数（峰值 + 实测区间 + 降速后速度），
  别写"快/很快"；
- 结尾给**一条**最优方案，不要罗列多选项。
- **⚠️ 用户问"我现在打哪个电话"/"我现在该做什么"时，他正在行动中——第一行只给那一个号码或那一个动作，
  一行说完，细节、备选、法条全部放后面。** 这种时候给"三选一"的表格是在挡路（他已经说了"我投诉试试"）。
  判断标准：用户的问题里有"现在"/"就"/"直接"这类词 = 要单一可执行答案，不要菜单。
