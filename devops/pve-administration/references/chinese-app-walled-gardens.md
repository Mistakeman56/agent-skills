# Chinese App Walled Gardens

## 闲鱼 (Xianyu / Goofish) — ❌ 完全不可访问

**结论：闲鱼无法通过任何自动化工具访问。** 它是一个纯 App 生态，网页版 (`goofish.com`) 只是 SEO 外壳。

### 测试结果（2026-05-11 全量验证）

| 工具 | 结果 | 详情 |
|------|------|------|
| **Bright Data `search_engine`** | ❌ | Google `site:goofish.com 开关电源` 只返回 1 个 SEO 首页和 1 个个人页面，无商品信息 |
| **Bright Data `scrape_as_markdown`** | ❌ | 搜索页只返回网站导航 + 分类链接（SEO 模板），无商品结果 |
| **`mcp_fetch_fetch`** | ❌ | `Page failed to be simplified from HTML` — JS 渲染页面无法提取 |
| **智谱 `web_search` (Bing)** | ❌ | 完全不返回闲鱼相关内容，全是无关 PDF |
| **`openwebsearch` (playwright 模式)** | ❌ | Playwright 未安装，不可用 |
| **Playwright MCP** | ❌ | Chromium 未安装在 homelab 环境 |

### 根本原因

1. **网页版搜索需要登录** — 未登录状态下 `goofish.com/search?q=xxx` 只渲染空的导航页
2. **商品数据不在 HTML 中** — 通过 JS + API 动态加载，搜索引擎无法索引
3. **反爬措施极强** — 阿里系的风控，自动化工具一律拦截
4. **没有公开 API** — 不像淘宝有开放平台

### 替代方案

用户只能在 **闲鱼 App 手动搜索**。Agent 可以做的：
- 帮用户制定筛选标准和关键词
- 根据用户发送的商品截图判断卖家是否靠谱
- 提供品类选购知识和价格参考

## 企业微信文档 (doc.weixin.qq.com) — ⚠️ 部分可访问

**已知限制（来自 memory）：**
- 分享链接在 agent 未登录状态下无法访问内容
- HTTP 200 但返回空白页，`userType=guest`
- 用户需要改用截图、复制粘贴文本、或导出文件来分享文档内容

## 通用模式：中国超级 App 的围墙花园

| 平台 | 网页版 | 搜索引擎索引 | Agent 可访问 |
|------|--------|:---:|:---:|
| 闲鱼 | 需要登录 | ❌ | ❌ |
| 企业微信文档 | 需要登录 | ❌ | ⚠️ guest 空白 |
| 淘宝/天猫 | 需要 JS | ⚠️ 部分 | ❌（反爬） |
| 京东 | 需要 JS | ✅ | ❌（反爬，只返回页脚） |
| 知乎 | 公开 | ✅ | ⚠️ robots.txt 限制 |
| 小红书 | 需要登录 | ❌ | ❌ |
| 抖音 | 需要 JS | ❌ | ❌ |

### Agent 处理策略

遇到用户要求从这些平台获取内容时：
1. **先判断可行性** — 对照上表，不要反复尝试（浪费 token）
2. **告知用户限制** — 一次性说清楚，提供替代方案
3. **可做的**：帮用户制定搜索词、筛选标准、给品类知识、分析用户发来的截图
4. **不可做的**：直接获取平台内商品/内容数据
