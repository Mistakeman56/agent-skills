## 概述

一个自包含的 SKILL.md 文件，把分散在 13 个数据源里的 A 股原始数据整合成 AI 编程助手直接能用的工具集。**V3.1彻底移除akshare依赖**，所有数据源改为直连HTTP API（零第三方数据封装依赖，仅mootdx保留TCP）。

```
行情层    mootdx + 腾讯财经 + 百度K线      K线(带MA5/10/20) + 五档盘口 + PE/PB/市值 + 指数/ETF
研报层    东财 reportapi + 同花顺 + iwencai  研报列表 / PDF下载 / 一致预期 / NL搜索
信号层    同花顺 + 百度股市通 + 东财         强势股 + 题材归因 + 北向资金 + 概念板块
                                             + 资金流向(push2) + 龙虎榜 + 全市场龙虎榜 + 解禁 + 行业对比
资金面    东财 datacenter + push2            融资融券 + 大宗交易 + 股东户数 + 分红送转 + 资金流(分钟+120日)
新闻层    东财 + 财联社（直连HTTP）           个股新闻 / 财联社快讯 / 全球资讯
基础数据  mootdx + 东财 + 新浪               季报37字段 / F10九大类 / 财报三表
公告层    巨潮 cninfo + mootdx               沪深北全量公告
```

## 关键能力详解

### 同花顺热点题材归因（最强信号）
```python
from a_stock_data import ths_hot_reason
df = ths_hot_reason("2026-05-20")
# 返回每只股票的名称、代码、涨幅%、以及 "题材归因" 字段
# 例: "算力租赁+Token工厂+AI政务" — 同花顺编辑部人工运营 tags
```

### 腾讯财经行情（零鉴权、不封IP）
```python
from a_stock_data import tencent_quote
quotes = tencent_quote(["688017", "300476"])
# 返回 PE(TTM), PB, 市值, 换手率, 涨跌停价, 振幅等46字段
```

## 集成方式

```bash
# 安装依赖
pip install mootdx requests pandas stockstats
# 仅 HTTP API 可用，mootdx TCP 需要国内IP才稳定
```

SKILL.md 文件可直接放入 `~/.claude/skills/a-stock-data/` 供 Claude Code 使用，或粘贴到 Hermes 的 prompt 中手动调用。

## 注意事项

- **mootdx TCP超时（海外服务器）**: mootdx 走TCP连通达信行情服务器(7709端口)，需要国内IP才稳定。海外环境建议走代理或跳过mootdx，仅用HTTP API（腾讯、东财、同花顺、百度）。
- **iwencai需要API Key**: 唯一需要付费/注册的数据源。其他27个端点全部免费无key。
- **数据源优先级**: mootdx(极低封IP) > 腾讯/东财HTTP(低封IP) > 同花顺(极低封IP,零鉴权)
- **V3.1刚修复**: 替换了4个失效接口（百度PAE资金流→东财push2），28端点全部实测通过贵州茅台600519验证。

## 使用场景

1. **盘前分析增强**: 叠加同花顺热点题材归因 + 北向资金流向 + 行业板块排名 → 知道今天资金在炒什么
2. **个股深度调研**: 研报列表 + 一致预期EPS + PE/PEG估值 + 龙虎榜席位 + 股东户数变化
3. **龙虎榜跟踪**: 每日全市场龙虎榜净买入排名 → 机构在买什么
4. **解禁预警**: 未来90天待解禁股票 → 提前规避解禁风险
5. **行业轮动**: 东财行业板块涨跌幅排名 → 看资金在往哪些板块流
