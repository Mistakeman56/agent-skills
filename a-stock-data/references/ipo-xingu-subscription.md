# A股打新（新股申购）规则速查（2026-08 宇树科技案例实测）

用户问"XX新股能买吗/怎么买/有50万限额吗"时使用。50万存款≠能打新——**打新看市值不看现金**，这是最常见的误解。

## 科创板/创业板打新的硬性条件（缺一不可）

1. **板块权限**：科创板需已开通（开通门槛=50万资产+2年交易经验，**开通后不撤**，不用保持50万）；创业板类似（10万+2年）。用户在券商APP查"科创板权限"是否已开。
2. **沪市/深市市值（关键！看的是股票市值，不是账户现金）**：
   - T-2日（申购日前2个交易日）往前20个交易日的**日均市值**
   - **每5000元沪市市值 = 1签额度（科创板500股/签）**；深市每5000元=1签（500股）
   - 现金躺着不算市值！必须持有对应市场的股票（沪市=60/688开头，深市=00/300开头）
   - 用户持仓中沪市票（长江电力、北方华创等）可算沪市额度

## 申购流程（打新日当天操作）

1. 券商APP → 查"我的申购额度"（直接显示可申购签数）
2. 申购日 9:30-15:00 点**新股申购** → 输**网上申购代码**（与股票代码不同，科创板7开头如787836）→ 按额度申购
3. 申购时**不用付钱**；T+2 公布中签 → 中签当日**日终前账户备足款**（一签500股×发行价）
4. 未中签不扣钱；中签弃购=拉黑名单6个月，别弃

## 定价参考
- 发行市盈率219倍/市销率35.89倍——**定价不便宜**；热门股（机器人/AI）首日大涨概率大但存在破发风险，破发概率相对低
- 新股估值查询可走 a-stock-data 主流程：腾讯行情(PE/PB) + 东财研报 + 同花顺一致预期

## 用户侧要点
- 用户问"存过50万能买吗"→ 回答：权限靠50万（已开通就行），**但打新额度看沪市股票市值，不是存款**；让用户查APP里的"申购额度"
- 用户在旅行/异地也不耽误，手机券商APP点几下即可
- 热门股中签率极低，主动说明"白嫖抽奖"预期，别让用户期待过高
